CleverFerret theme system

A theme is three layers that can be combined freely: a layout pack (shape, navigation, type), a colour pack (MD3 roles, metal, reader pages) and an effect pack (sheen, glow, glass, pattern, motion). Any layout works with any colour pack and any effect pack: 7 × 24 × 8 = 1,344 themes. Media mode then adjusts chrome density for browsing, reading, listening and watching, without changing the theme.

Media modes

Media mode is not a theme choice. Each surface sets its own chrome density and controls, the colour pack stays the same, and effects are limited to the slots listed.

BrowseHome, Library, Settings. Full navigation from the layout pack, 48dp targets, all effect slots active.density: layout · effects: all
ReaderChrome hides on tap. The page uses the pack's Day, Sepia or Night colours. The text canvas never gets pattern, grain or glow; effects apply to the chrome only.density: compact chrome · effects: chrome
PlayerArtwork is the hero. Metal and shimmer appear on the 72dp play button, title and chip. The active timer (sleep) is tinted primary.density: spacious · effects: CTA + title
VideoChrome sits over a #000 scrim at 60%. The pack supplies only the progress and focus accent. Everything else is off, including shimmer, so nothing competes with the picture.density: overlay · effects: focus glow only

Composed theme · portable JSON

Stored as three IDs plus overrides, and resolved at runtime into CFTokens + MD3 ColorScheme. This replaces CleverFerretTheme (22 enums), MediaThemes and CFLayout. The layout is no longer locked to a palette.

Default
