CleverFerret theme system

A theme is three layers that combine freely: a layout pack (shape, navigation, type), a colour pack (MD3 roles, metal, status, reader pages) and an effect pack (sheen, glow, glass, pattern, motion). Any layout works with any colour and any effect: {{ comboFormula }}. Media modes then adjust chrome density for browsing, reading, listening and watching, and library-management patterns cover matching, repairing, filing and tagging.

Library management patterns

CleverFerret catalogues like Calibre and files like Plex. New media passes a five-stage pipeline: it is matched against metadata sources, repaired if badly formatted, renamed to a server-ready path, and tagged. These patterns appear in the Import inbox, Fix match, File repair, Sort rules, Tag explorer and Calibre plugins screens.

Composed theme · portable JSON

Stored as three IDs plus motion and reader page, and resolved at runtime into CFTokens + MD3 ColorScheme. This replaces CleverFerretTheme (22 enums), MediaThemes and CFLayout, so the layout is no longer locked to a palette.

{{ json }}
Legacy → colour packNAVY_GOLD → navy-gold, EMERALD_SILVER → emerald-silver … PAPER_INK → paper-ink. COPPER_BRONZE, STEEL_TITANIUM and COBALT_CHROME move to the metal brush of the nearest pack. EInkTokens and HighContrastTokens become the Accessibility family.
Legacy → effect packANCIENT_BRONZE, SILVER_ARCHITECT and OBSIDIAN_TECH become Architect on Royal Bronze, Royal Silver and Slate Cyan. Patterns, crystal glow and shimmer carry over.
DefaultCompose / Navy Gold with Sheen, which matches today's modern surface. Motion defaults to System.
